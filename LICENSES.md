# Resource and licensing register

All art in this increment is hand-authored original SVG geometry in `tools/build.py` (cyan player, magenta spike, and abstract grid backdrop). The project includes no Geometry Dash/SubZero artwork, extracted resources, commercial soundtrack, or third-party code/assets. The game title is used only to identify the intended compatibility target. Audio is absent in this prototype. Project source is distributed under MIT; see `LICENSE`.
