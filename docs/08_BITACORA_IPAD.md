## Cómo editar desde GitHub en iPad

1. Abre [la rama del cuaderno](https://github.com/Dracalight/Blocks/tree/research/school-decision-workspace-20261105).
2. Comprueba que dice `research/school-decision-workspace-20261105` y no `main`.
3. Abre `docs/02_DECISIONES_OWNER.md` o este archivo.
4. Pulsa el icono de lápiz, edita y selecciona **Commit changes** sobre la misma rama.
5. Verifica que tu cambio aparece en la vista de archivos y que el commit existe.
6. No hagas PR hacia `main`.

Si la edición web falla, conserva un borrador local en el iPad; solo marca COMPLETE cuando haya commit confirmado.
