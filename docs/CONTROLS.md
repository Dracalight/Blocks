# Keyboard controls

Click the green flag, select **1 NORMAL**, **2 HARD** or **3 CHAOS**, and press **Enter**. Normal is the default.

| Key | Action | Response |
| --- | --- | --- |
| Left Arrow | Move left | Immediate step, 160 ms initial delay, then every 50 ms. |
| Right Arrow | Move right | Same controlled repeat. |
| Down Arrow | Soft drop | Immediate step, then every 50 ms; 1 point per row. |
| Up Arrow | Rotate clockwise | One rotation per press; release before another rotation. |
| Space | Hard drop | 2 points per row; holding cannot drop the next piece. |
| C | Hold | Once per piece; release before pressing again. |
| P | Pause / resume | All game clocks freeze while paused. |
| R | Restart | New board in the selected mode. |
| 1 / 2 / 3 | Select mode | From menu, pause or Game Over; clears the board and returns to the menu. |
| Enter | Start | From menu or Game Over. |

On iPad, connect the physical keyboard, use landscape orientation, and focus the stage. Keep the browser in the foreground. Background tabs may be throttled; the game discards delays longer than 100 ms per tick to avoid a catch-up avalanche. Press P before leaving the game.

HOLD and SCORE appear on the left, the board in the center, NEXT / LEVEL / LINES / MODE on the right. Chaos warnings appear on the left. No panel or sprite accepts touch input.

Physical iPad keyboard / Safari behavior has not yet been verified on a device.
